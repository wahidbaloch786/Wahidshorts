# WahidShorts

WahidShorts is a Flutter starter for a short-video social media app.

## What works now
- Full-screen vertical video feed
- Swipe between videos
- Auto-play and looping
- Like/unlike
- Like counter
- Comment UI placeholder
- Share UI placeholder
- Profile screen placeholder

## Next production stage
Connect Firebase for:
- Real email/password and Google login
- User profiles
- Video upload to Cloud Storage
- Firestore video feed
- Likes, comments, follows and saved videos
- Notifications
- Reports and blocks
- Admin moderation
- Analytics

## Run
1. Install Flutter on a computer/cloud Flutter environment.
2. Open this folder.
3. Run `flutter pub get`.
4. Run `flutter run`.

For Play Store, create a signed Android App Bundle (`.aab`) after Firebase and production settings are complete.
